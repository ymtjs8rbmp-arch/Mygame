# Esther's Kindergarten Adventure — Deluxe

A full-screen, mobile-friendly browser game for GitHub Pages.

## Play
1. Upload `index.html` to a GitHub repository.
2. In repository Settings → Pages, deploy from the main branch/root.
3. Open the published site on phone or desktop. Tap once to enable browser audio.

## Included
- Animated loading screen with “Love you Esther!”
- Colorful menu, eight level choices, platform gameplay and coin pickups
- Kindergarten question before and after each level
- Puppy color/accessory customization
- Pretend-coin shop and Word Drop spelling mini-game
- Parent bonus code `0919` grants 500 pretend coins
- Sound effects made with Web Audio (no external audio files)
- No payment processing, purchases, card fields, or external dependencies

Artwork is original stylized cartoon puppy artwork rather than official Bluey assets. Controls: arrows/A-D to move, Up/W/Space to jump, or the on-screen controls.
