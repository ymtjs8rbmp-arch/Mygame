# Esther's Kindergarten Adventure — Dreamworld Deluxe (V5)

A colorful, mobile-friendly browser learning game for GitHub Pages.

## What's new in V5
- Redesigned the original puppy mascot with expressive eyes, floppy ears, a defined muzzle, soft cheek details, and layered blue-and-tan cartoon markings.
- Matched the menu/customization puppy and the in-level platformer character more closely so the same equipped skin carries across the game.
- Preserves the rainbow, unicorn, galaxy, and solid-color skin options, accessories, shop, music, and sound effects.

## What's new in V3
- Expanded puppy customization with 16 colors, including Rainbow Magic, Unicorn Aura, Starlight, Crystal Ice, and Mystic Lavender.
- 12 accessories and a bigger pretend-coin shop with 20 fun items, pets, trails, and fantasy gear.
- Saves coins, current level, owned shop items, puppy color, accessory, and completed levels locally on the same device.
- Keeps all the original 8 levels, 60 kindergarten questions, 2D platform adventure, Word Drop spelling game, sound effects, and touch/keyboard controls.
- Child-friendly and free: no real-money purchases, payment processing, or card details.

## Run it
Open `index.html` in a modern browser, or upload `index.html` to the root of a GitHub repository and enable GitHub Pages under **Settings → Pages**.

## Controls
Desktop: Left/Right arrows or A/D to move; Up/W/Space to jump. Mobile: use the on-screen movement and jump buttons.

The parent bonus code remains `0919` and adds 500 pretend coins. Game progress is stored locally in your browser; clearing browser storage resets it.
