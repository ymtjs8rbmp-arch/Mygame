# Esther's Kindergarten Adventure — Dreamworld v25

A colorful, kid-friendly learning platformer made as a static website for GitHub Pages.

## v25 updates
- Headphones now sit behind the puppy's head, with ear pads at the sides rather than floating across the face.
- Added equippable Sparkle Shoes; the puppy's feet change appearance when shoes are equipped.
- Organized the Star Shop into All, Shoes, Accessories, Skins, and Halloween sections. Shop items have Preview and Equip actions.
- Simplified the everyday wardrobe to 10 main accessories and 5 main skins, with a small separate collection of Halloween accessories and skins.
- Preserved the existing levels, learning games, progress, and family menus.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Replace the repository's root `index.html` with the included file.
3. Commit the change and wait for GitHub Pages to publish.
4. Refresh the website. If an old version remains cached, close and reopen the page.

This game saves progress locally in the browser on the device being used. Tokens are pretend game rewards only.
