# Esther's Kindergarten Adventure — Dreamworld v23

This update builds on the existing v19 game and adds:
- Scrollable parent dashboard on mobile and desktop.
- Six distinct selectable backdrops plus Halloween Haunt.
- Tap the menu puppy to hear a real recorded dog bark (CC0-labelled source).
- Removed the bright white glow/oval behind the dress-up preview.
- Wings now sit behind the puppy, with redesigned pastel fairy wings and purple bat wings.
- Level 1 now starts with a simple 1 + 1 preschool math question, with additional early-level counting and beginner addition/subtraction questions.
- Halloween Howl original synthesized soundtrack automatically used for levels while Halloween Haunt is selected.
- Pumpkin Patch Pup skin plus Pumpkin Hat, Bat Wings, Little Witch Hat, and Ghost Backpack.

## GitHub Pages
Replace the root `index.html` and `README.md` in your existing repository with these files. Progress and settings are stored locally in the browser on that device. The parent code is a basic in-game gate, not strong security.


Audio asset: Dog bark MP3 from SFXMint, labelled CC0/public-domain on its animal-calls page (https://sfxmint.com/sets/animal-calls). The bark loads from that URL, so the puppy bark needs an internet connection. The dog-bark sound source was identified from its published license information.


Version 22 fix: the beach flag in Level 2 is anchored to the level world and scrolls away naturally as the player moves, instead of staying attached to the screen.


Dreamworld v23 updates: removed the extra reset control from the in-game HUD; Word Drop advances automatically after a correctly spelled word; level questions are randomly selected and avoid repeats until the question pool has been used; exiting a level resets that run; and the always-unlocked Halloween level features pumpkin and ghost platforms plus the unlockable Ghost Pup costume.
