# Esther's Kindergarten Adventure — Deluxe Edition

A colorful, full-screen, mobile-friendly browser game designed for GitHub Pages.

## Features
- Bright cartoon-inspired loading screen and main menu with “Love you Esther!”
- 60 kindergarten-friendly questions, used at the start and finish of levels
- Eight selectable levels and 2D platform gameplay
- Original cartoon puppy with color/accessory customization
- Collectible coins, pretend-coin shop, and Word Drop spelling mini-game
- Parent bonus code `0919` grants 500 pretend coins
- Synthesized sound effects for menu taps, jumps, coins, answers, and celebrations
- Keyboard and touch controls; responsive phone and desktop layouts
- No external dependencies, no payment processing, and no card details

## Publish on GitHub Pages
1. Unzip this package.
2. Upload `index.html` to the root of your GitHub repository.
3. Open **Settings → Pages** and deploy from the `main` branch and `/ (root)`.
4. Open the Pages URL on your phone or computer. Tap a button once to enable browser audio.

## Controls
- Desktop: Left/Right arrows or A/D to move; Up/W/Space to jump.
- Phone/tablet: use the on-screen arrows and jump button.

The artwork is an original stylized puppy and interface inspired by the colorful reference board, not official Bluey assets. All coins and the parent bonus are pretend in-game rewards.
