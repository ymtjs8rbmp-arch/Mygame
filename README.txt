ESTHER'S PUPPY ADVENTURE
========================

Install:
1. Unzip this folder.
2. Upload index.html to the root of your GitHub Pages repository.
3. Commit the changes and wait for GitHub Pages to publish.

Includes:
- Full-screen responsive layout intended to avoid page scrolling and browser zooming.
- Opening loading screen: “Love you Esther!”
- Main game menu with Play, Select Level, Customize, Shop, Word Drop, and How to Play.
- In-level menu/pause, X exit button, next-level and select-level flows.
- Kindergarten questions at the start and end of each level.
- Touch controls and keyboard controls.
- Pretend coin shop and parent bonus code 0919. There are NO real payments, card forms, or payment links.

Art note:
The puppy is a CSS-drawn blue-heeler-inspired character, not official Bluey artwork. The game is a self-contained browser prototype; gameplay and rendering may need further polish/testing on the target phone.
