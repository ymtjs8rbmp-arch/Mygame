Puppy Adventure Jump — Learning Platformer
==========================================

HOW TO USE
1. Unzip this folder.
2. Upload index.html to the root of your GitHub Pages repository.
3. Commit the change and wait for GitHub Pages to publish.

FEATURES
- Bright, cheerful platform-jumping mini game.
- Keyboard and touchscreen controls.
- Collectible coins, kindergarten quiz questions at both the beginning and end of every level, plus level progression.
- Customize screen and pretend coin shop.
- Parent bonus code is 0919. Entering it awards 500 in-game coins and opens the “Thank you! Love you!” screen.
- NO payment processing, no credit-card fields, no real purchases, and no external payment links.

NOTE
This is a small browser game prototype. The puppy is a generic emoji-style character, not official Bluey artwork. If you share it publicly, use characters and art you have permission to use.
